CAPYBARA BOUNCE RUN

1. Extract ZIP.
2. Open folder in VS Code.
3. Install: py -3.13 -m pip install pygame opencv-python mediapipe numpy
4. Run: py -3.13 capybara_bounce_run.py

The hand_landmarker.task model is downloaded automatically on first run.
ESC/Q = quit; SPACE = manual jump; fist = jump; raise hand = high jump; R = restart after game over.
Camera and HSV previews are embedded in the game window.
