Game endless runner menggunakan Python, Pygame, OpenCV, dan deteksi warna HSV.
Fitur
- Game fullscreen dengan karakter capybara.
- Deteksi objek merah, hijau, dan biru menggunakan HSV.
- Visualisasi kamera dan hasil masking HSV.
- Sistem skor, nyawa, rintangan, dan game over.
Kontrol Warna
- Merah: lompat biasa.
- Hijau: lompat tinggi.
- Biru: merunduk.
Instalasi
Pastikan Python 3.13 sudah terpasang, kemudian jalankan:
Menjalankan Game
py -3.13 capybara_bounce_run.py
